# Nguyen Ngoc Thien Portfolio

Responsive profile/portfolio website built with ReactJS + Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Update personal information

Open `src/App.jsx` and edit the `profile`, `skills`, `experiences`, and `products` constants near the top of the file.

### Important
The sample email is set to `thien.nguyen@example.com`. Replace it with your preferred public contact email before deployment.
